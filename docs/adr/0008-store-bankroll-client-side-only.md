# Store bankroll settings client-side only

The bankroll management feature (total bankroll, Kelly fraction, maximum-stake cap) stores its settings exclusively in the user's browser (localStorage, exposed through a `useSyncExternalStore` hook). Bankroll values are never transmitted to the server, are not persisted in analysis snapshots, and are not shared across devices. This keeps the product inside the ADR 0003 analysis-only boundary and ADR 0005 identity/financial-data minimization without requiring authentication or a user identity, which the guest-first beta deliberately does not have. The per-analysis stake output is framed as an arithmetic illustration (EV + fractional Kelly + cap) on user-supplied inputs — the win probability defaults to the analysis's historical hit rate (a descriptive statistic, per CONTEXT.md) and may be overridden by the user's own estimate, always labeled as such. If a future validated predictive model (ADR 0004) is introduced, its estimated probability will occupy the same labeled slot; the storage decision for bankroll settings does not change unless a multi-device sync feature is explicitly requested and re-reviewed.
