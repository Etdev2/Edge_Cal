# Issue tracker: GitHub

Issues and specifications live in `Etdev2/Edge_Cal` GitHub Issues.

## Conventions

- Use GitHub Issues for specifications, decisions, and implementation tickets.
- Pull requests are not a feature-request or triage surface.
- Use the connected GitHub integration when available; otherwise use `gh`.

## Wayfinding operations

- The canonical map is one issue labeled `wayfinder:map`.
- Decision tickets are child issues labeled by type.
- Use GitHub sub-issues and native dependencies when available.
- Claim work by assigning the issue before beginning.
- Resolve a decision with a comment, close its ticket, and link the result from the map.
